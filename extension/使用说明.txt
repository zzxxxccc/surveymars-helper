SurveyMars 课堂填表助手 — Windows / Edge / Chrome

首次安装（只需一次）
1. 将 ZIP 解压到固定文件夹。不要仅在 ZIP 预览中打开。
2. Edge 地址栏输入 edge://extensions；Chrome 输入 chrome://extensions。
3. 打开“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择包含 manifest.json 的“SurveyMars助手”文件夹。
5. 点击浏览器扩展菜单中的“SurveyMars 课堂填表助手”。建议固定到工具栏。

日常使用
1. 输入姓名、学号，点击“保存信息”。学号按文本处理，开头的 0 不会被删除。
2. 在助手页面 Ctrl+V 粘贴二维码截图，或选择/拖入图片；也可以粘贴问卷链接。
3. 点击“打开表单并自动填写”。
4. 核对课程、姓名、学号，再点击原表单的 Submit。

适配情况
已检查课堂示例问卷的姓名和学号字段。
实际字段：Name（q1）、Student ID（q2）。程序依据题目文字识别，不盲目按顺序填写。
不会覆盖已有内容，也不会自动提交。若字段有歧义或未识别，会显示提示。
仅由助手打开的那一个问卷标签页会触发填写；普通浏览其他问卷不会自动填入信息。
登录、验证码、已关闭的问卷及其他题型需手动处理。跨域跳转可能无法自动填写。

隐私与卸载
二维码图片在本机解析，不上传。姓名学号保存在浏览器本地扩展存储（未加密，不云同步）。
点击“打开表单并自动填写”后，个人信息会写入目标 SurveyMars 页面。
可在助手中清除个人信息，或在扩展管理页删除扩展。

验证范围
已用提供的原始照片成功解码，并检查在线表单字段；未向真实课堂提交测试答卷。
扩展需要在用户的 Edge/Chrome 中加载后验证完整流程。

第三方组件：jsQR 1.4.0，Apache-2.0，见 LICENSE-jsQR.txt。



多人版 v1.1.0

在名单框每行输入“姓名,学号”，也可以从 Excel 复制姓名、学号两列（不要带表头），点击保存名单。学号保留开头的 0，重复学号会被拒绝。

识别一次二维码后，点击“打开下一位并填写”。在表单里核对并点击 Submit，看到成功提示后回到助手，为此人点击“确认已提交”，再打开下一位。进度由使用者确认，不是平台提交回执。

新问卷链接分别记录进度；同一链接的新一轮统计先点击“重置当前表单进度”。重新填写可能重复提交，请先核实。若平台限制同一设备提交次数，请联系表单管理员调整。

更新：下载新包，解压后在 edge://extensions 中移除旧版再加载新版 extension 文件夹，或用新版文件覆盖原 extension 文件夹后点击扩展卡片上的刷新。覆盖原文件并刷新可保留本机信息；旧版个人信息会转为单人名单。
