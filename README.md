# SurveyMars 课堂填表助手

适用于 Windows 的 Edge / Chrome 扩展。姓名和学号保存一次，以后粘贴、拖入或选择二维码截图，即可识别问卷链接并自动填写。核对后由使用者在原表单点击 Submit。

## 安装

1. 点击 Code → Download ZIP，解压到固定文件夹。
2. 在 Edge 打开 edge://extensions，或在 Chrome 打开 chrome://extensions。
3. 开启开发人员模式，选择“加载解压缩的扩展”，选择 extension 文件夹。
4. 点击扩展图标，填写并保存姓名、学号。

## 使用

在助手页面按 Ctrl+V 粘贴二维码图片，或拖入、选择图片。也可直接粘贴 SurveyMars 问卷链接。点击“打开表单并自动填写”，核对课程和个人信息后提交。

## 隐私和限制

图片在本机解析；姓名和学号保存在本地扩展存储，不进行云同步。打开表单并填写后，信息会写入目标 SurveyMars 页面。可随时清除保存的信息。

依据题目文字识别 Name / 姓名、Student ID / 学号，不覆盖已有答案；字段有歧义时保留给使用者填写。不自动提交。登录、验证码、已关闭问卷和其他题目需要手动处理。

已验证示例二维码解码、在线字段结构以及自动填写逻辑；完整扩展流程仍需在 Edge / Chrome 加载后验证。没有提交真实课堂测试答卷。

## 开发验证

无需构建或下载依赖。使用 Node.js 运行 `node test.cjs`，检查字段识别、题目顺序、学号前导零、已有内容及歧义处理。

## 多人版 v1.1.0

在名单框每行输入“姓名,学号”，也可以从 Excel 复制姓名、学号两列（不要带表头），点击保存名单。学号保留开头的 0，重复学号会被拒绝。

识别一次二维码后，点击“打开下一位并填写”。在表单里核对并点击 Submit，看到成功提示后回到助手，为此人点击“确认已提交”，再打开下一位。进度由使用者确认，不是平台提交回执。

新问卷链接分别记录进度；同一链接的新一轮统计先点击“重置当前表单进度”。重新填写可能重复提交，请先核实。若平台限制同一设备提交次数，请联系表单管理员调整。

更新：下载新包，解压后在 edge://extensions 中移除旧版再加载新版 extension 文件夹，或用新版文件覆盖原 extension 文件夹后点击扩展卡片上的刷新。覆盖原文件并刷新可保留本机信息；旧版个人信息会转为单人名单。
